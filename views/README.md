# 조회수 (Cloudflare Worker + D1)

글 조회수를 **즉시** 세고 즉시 보여주기 위한 작은 서버입니다.
사이트 빌드와는 완전히 별개로 돕니다.

---

## 설치 순서

**어디서 실행하나요?** 맥의 아무 터미널이든 됩니다(iTerm, 기본 터미널,
VS Code 하단 터미널 전부 같습니다). 중요한 건 **디렉터리** 입니다.
반드시 이 `views/` 폴더 안에서 실행하세요. `wrangler.toml` 이 있는 곳을
기준으로 동작합니다.

```bash
cd ~/Workspace/Projects/m4ch77/views
```

### 1. 도구 설치 (한 번만)

```bash
npm install
```

### 2. Cloudflare 로그인

```bash
npm run login
```

브라우저가 열리고 "Allow" 를 누르면 터미널로 돌아옵니다. 계정 정보는
이 컴퓨터에만 저장되고 저장소에는 들어가지 않습니다.

### 3. 데이터베이스 만들기

```bash
npm run db:create
```

출력 중에 이런 줄이 나옵니다.

```
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

**그 값을 복사해서 `wrangler.toml` 의 `database_id = ""` 안에 넣으세요.**
이걸 안 하면 다음 단계에서 "D1 binding not found" 가 납니다.

### 4. 표 만들기

```bash
npm run db:init
```

`views` 표와 인덱스가 생깁니다. 이미 있으면 아무 일도 하지 않습니다
(`CREATE TABLE IF NOT EXISTS`).

### 5. 올리기

```bash
npm run deploy
```

마지막에 주소가 나옵니다.

```
https://m4ch77-views.<계정이름>.workers.dev
```

**이 주소를 알려주세요.** `build/config.mjs` 한 줄에 넣으면 사이트에
조회수가 켜집니다.

## 왜 직접 만들었나

GoatCounter 의 카운터 표시는 **최대 4시간 캐시**됩니다(공식 문서). 숫자가
바로 보여야 해서 조회수만 따로 셉니다. 유입 경로·브라우저 같은 일반 분석은
GoatCounter 가 계속 담당합니다.

## 왜 AWS 가 아닌가

나중에 AWS 계정을 옮겨도 데이터가 그대로여야 한다고 하셨습니다.
Cloudflare 에 두면 **AWS 이관과 아무 상관이 없어집니다.**

## 무엇을 1회로 세는가

기준은 **기기 × 브라우저 × 글 × 24시간** 입니다.

| 상황 | |
| --- | --- |
| 같은 글을 50번 새로고침 | +0 |
| 다음 날 다시 읽음 | +1 |
| 다른 사람이 읽음 | +1 |
| 같은 사람이 사파리로도 읽음 | +1 |
| 다른 글을 읽음 | +1 |

판단은 **브라우저**가 `localStorage` 로 합니다. 서버에 방문자를 식별할
값을 남기지 않기 위해서입니다. 쿠키도 쓰지 않습니다. 서버는 명백한
크롤러만 걸러냅니다.

정직하게 말하면 완벽한 순방문자 수는 아닙니다. 시크릿 모드나 저장소를
지우면 다시 셉니다. 더 정확하게 하려면 서버가 방문자를 식별해야 하는데,
그 교환은 하지 않는 편이 낫다고 봤습니다.

## 저장되는 것

```
path        /writing/scroll-motion
count       128
first_seen  2026-08-06T...
updated_at  2026-08-07T...
```

방문자에 대한 정보는 **한 줄도 저장하지 않습니다.**

## 한도

무료 플랜에서 **쓰기 10만 행/일, 읽기 500만 행/일, 저장 5GB** 입니다.
개인 블로그 조회수로는 남습니다.

## 엔드포인트

| | |
| --- | --- |
| `POST /view` | 1 올리고 현재 수 반환 |
| `GET /view?path=…` | 올리지 않고 현재 수만 |
| `GET /views` | 전체 (목록 조회수 정렬용) |

우리 도메인에서 온 요청만 받고, 경로 형태도 `/` 와 `/writing/<이름>` 으로
제한합니다. 아무 경로나 넣어 표를 더럽히지 못하게 하려는 것입니다.

## 백업

하루 한 번 GitHub Actions 가 전체 숫자를 읽어 저장소에 스냅샷으로
커밋합니다. **조회마다 커밋하지 않습니다.** 서비스를 바꾸거나 계정을
옮겨도 git 에 숫자 이력이 남게 하려는 보험입니다.
