    없음 많음

    선택한 날 ----.--.--

    1. CSS 스크롤 스냅은 컨테이너에 종류를 걸고 자식에 지점을 건다. 화면보다 긴 섹션은 스냅에서 빼야 안쪽이 갇히지 않는다.
    2. CSS 100vw 는 스크롤바를 포함한다. 화면 끝에 무언가를 맞출 때는 clientWidth 를 재는 편이 안전하다.
    3. a11y 색 토큰이 정의되지 않은 자리에서 color 는 브라우저 기본값으로 떨어진다. 다크 모드에서는 그게 흰색이라 밝은 배경에서 사라진다.
    4. JS scroll-behavior: smooth 가 켜져 있으면 scrollTo 로 만든 애니메이션과 싸운다. 직접 굴릴 때는 auto 로 잠깐 내려야 한다.
